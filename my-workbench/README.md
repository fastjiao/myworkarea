## 具体操作
- [ ] 去掉独立容器的边框和阴影
    - 不要让左侧导航、顶部标题栏、歌曲列表、底部播放栏各自为政。
    - 做法： 移除所有模块之间的分割线和外边框。让内容直接“浮”在统一的背景上，或者让相邻模块共享同一个背景色块。
- [ ] 采用“沉浸式/通栏”布局
    - 现在的顶部栏和底部栏像是贴在屏幕上的两张纸。
    - 做法： 让左侧导航栏的背景色一直延伸到屏幕最底端；让底部播放栏变成半透明毛玻璃，直接覆盖在列表上方，而不是把列表“顶”上去。这样视觉上就是一个完整的画面。
- [ ] 用“留白”代替“线条”做分隔
    - 模块之间不需要线，只需要足够的间距。
    - 做法： 歌曲列表区域不要加背景框，直接让文字排在主背景上。通过增大行高、调整左右Padding来区分内容区，而不是画一个矩形把它框起来。
- [ ] 统一背景层级
    - 现在可能有3-4种不同的灰/白色背景在打架。
    - 做法： 整个页面只用1个主背景色（比如极浅的灰白 #F7F8FA 或深色模式下的 #121212）。只有被Hover或被选中的元素才出现次级背景色。
